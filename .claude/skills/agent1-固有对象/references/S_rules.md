## 1. S1 更新意愿（权重 0.5【待校准】）

> 输入：业主改造意愿 + 政府公开信息 + 更新意愿信号词典（由 [RETRIEVED CONTEXT] 被动注入）。

### 1.1 评分维度（V1 §1.3 L57-59）

| 维度 | 数据来源 | 评分占比（参考） |
|---|---|---|
| 业主主动申请意愿 | 用户填写 + 业主自述 | 40% |
| 历史业态调整次数 | 政府公开信息 + [RETRIEVED CONTEXT] | 30% |
| 配合度信号（是否参与政府试点 / 是否签订意向协议） | 用户填写 + 政府公开信息 | 30% |

### 1.2 评分映射表（V1 §1.3 L57 + 本 V2 细化）

| 触发条件 | S1 分数 | 编号 | 数据来源 |
|---|---|---|---|
| 业主主动申请改造（≥80% 共有人同意 + 已提交改造意向书） | **100** | S1.100 | 用户填写 + 意向书 |
| 业主被动响应但多数同意（50-80% 共有人同意 + 无明确反对） | **70** | S1.70 | 用户填写 |
| 业主中立 / 未明确表态（同意率难以判断） | **50** | S1.50 | 用户填写 |
| 业主被动响应且部分反对（30-50% 反对 + 50% 同意） | **40** | S1.40 | 用户填写 + 听证记录 |
| 业主反对（<50% 同意 / 多数反对 / 历史行政诉讼） | **30** | S1.30 | 用户填写 + 政府公开信息 |
| 业主数据完全缺失 | **null** | S1.null | 触发降级（详见 SKILL.md §6 F2） |

### 1.3 S1 评分步骤（LLM 推理时按以下顺序）

1. 读用户填写的「业主资质」字段，判断同意率（≥80% / 50-80% / <50%）
2. 查 [RETRIEVED CONTEXT] 的「业主历史业态调整次数」+「政府公开信息」
3. 按评分映射表对照，输出 S1 分数 + 编号（如 `S1.100`）
4. 若同意率难以判断 → S1.50（中性）
5. 若业主数据完全缺失 → S1.null（触发降级）

## 2. S2 可经营性（权重 0.5【待校准】）

> 输入：业态方向 + 运营模式 + 物理参数（层高 / 结构 / 建筑面积 / 区位）。

### 2.1 评分维度（V1 §1.3 L60-62）

| 维度 | 数据来源 | 评分占比（参考） |
|---|---|---|
| 层高满足业态（商业 ≥ 4.5m / 办公 ≥ 3.0m / 文旅 ≥ 5.0m / 工业 ≥ 6.0m） | 物理参数 | 30% |
| 结构适配（框架结构优于砖混 / 木结构） | 物理参数 | 20% |
| 区位客流基础（城市核心 > 中环 > 郊区） | 物理参数.区位 | 30% |
| 业态 × 运营模式组合（商业+自持 > 商业+出租 > 文旅+委托 > 工业+出租） | 业态 + 运营模式 | 20% |

### 2.2 评分映射表（V1 §1.3 L60 + 本 V2 细化）

| 业态 | 区位 | 运营模式 | S2 分数 | 编号 |

| 商业 | 城市核心 | 自持运营 / 合作开发 | **100** | S2.100 |
| 商业 | 城市核心 | 出租 / 委托 | **90** | S2.90 |
| 商业 | 中环 | 自持 / 合作开发 | **85** | S2.85 |
| 商业 | 中环 | 出租 / 委托 | **75** | S2.75 |
| 办公 | 城市核心 / 中环 | 自持 / 出租 | **75** | S2.75 |
| 办公 | 郊区 | 自持 / 出租 | **65** | S2.65 |
| 文旅 | 城市核心 / 中环 | 委托 / 合作开发 | **65** | S2.65 |
| 文旅 | 郊区（无客流基础） | 委托 | **50** | S2.50 |
| 工业仓储 | 任意 | 任意（无改造价值） | **30** | S2.30 |
| 业态 / 运营模式 / 区位 任一缺失 | — | — | **null** | S2.null（触发降级） |

### 2.3 S2 评分步骤（LLM 推理时按以下顺序）

1. 读用户填写的「业态方向」「运营模式」「物理参数.区位」
2. 按评分映射表对照，找到对应行
3. 输出 S2 分数 + 编号（如 `S2.100`）
4. 若业态不在表内（如新兴业态「医养结合」）→ 取最接近的业态（医养结合 ≈ 商业 + 文旅 中间值 ≈ S2.75）
5. 若任一关键字段缺失 → S2.null（触发降级，详见 SKILL.md §6 F2）

## 3. 总分公式与阈值映射

### 3.1 总分公式

```
S 总分 = S1 × 0.5 + S2 × 0.5
```

**约束**：

- S1 / S2 任一为 null → S 总分不可算，触发降级（详见 SKILL.md §6 F2）
- 权重 0.5 / 0.5【待校准】，本 V2 严格落地 V1 §1.3 锚定值，**禁止 LLM 自调权重**

### 3.2 阈值映射表（V1 §1.4 L70-72 逐字保留）

| S 总分 | 灯色 | 建议动作 | 编号 | 备注 |
|---|---|---|---|---|
| `S 总分 ≥ 75` | green | 可推进 | S总分.>=75 | H 全 green 时才生效；H 任一 yellow 时强制 yellow |
| `60 ≤ S 总分 < 75` | yellow | 条件推进 | S总分.60-75 | 任一 H yellow 时与 H yellow 叠加，仍 yellow |
| `S 总分 < 60` | red | 终止 | S总分.<60 | H 全 green 但 S 总分过低，灯色降级 red |

### 3.3 计算示例

| 场景 | S1 | S2 | S 总分 | 灯色 |
|---|---|---|---|---|
| 业主主动申请 + 商业核心区 | 100 | 100 | 100 | green |
| 业主被动响应 + 办公中环 | 70 | 75 | 72.5 | yellow |
| 业主反对 + 文旅郊区 | 30 | 50 | 40 | red |
| 业主中立 + 商业核心区 | 50 | 100 | 75 | green（边界） |
| 业主主动申请 + 工业仓储 | 100 | 30 | 65 | yellow |

## 1. 5 类失败模式定义（V1 §5 L281-285 逐字保留）

| # | 失败模式 | 标准化定义（V1 §5 L281-285 逐字） |
|---|---|---|
| 1 | **招商失败** | 招商失败：招商前置条件缺失（可租赁面积不足 / 区位客流薄弱） |
| 2 | **退出受阻** | 退出受阻：退出策略与融资期限 / 资产属性不匹配，路径不清晰 |
| 3 | **改造超预算** | 改造超预算：文保或结构硬约束高，改造模式受限致成本失控 |
| 4 | **业态误判** | 业态误判：业态方向 IRR 低于业态门槛基准下限 |
| 5 | **施工引发周边协调失败** | 施工引发周边协调失败：周边协调条件复杂（文保周边 / 密集区） |

## 2. 高危触发条件（与上表一一对应）

### 2.1 招商失败高危

**触发任一即判 red**：
- 可租赁面积 < 业态最低门槛（商业 5000㎡ / 办公 3000㎡ / 文旅 8000㎡，【待校准】）
- 区位客流评级 < D 级（A 为最优，E 为最差）

**字段来源**：
- agent1.可租赁面积 / agent1.物理参数.可租赁面积 / 用户输入 scale
- agent1.区位客流评级（来自 agent1 物理参数评估）

### 2.2 退出受阻高危

**触发任一即判 red**：
- 融资期限与持有年限严重错配（融资期限 < 持有年限 / 2）
- 资产属性禁止 REITs 退出（资产属性字段含"禁止"关键字 + 退出策略含 "REITs"）

**字段来源**：
- agent3.融资期限 / agent3.期限
- agent3.持有年限 / agent1.持有年限
- agent3.退出策略 / agent1.退出策略
- agent1.资产属性

### 2.3 改造超预算高危

**同时满足以下 3 条即判 red**：
- 文保等级 = "核心保护"
- 改造模式 = "保留微更新"（被迫收敛）
- 改造成本倍数 > 1.5× 基准

**字段来源**：
- agent1.文保等级 / agent1.文保约束 / agent1.物理参数.文保等级
- agent1.改造模式 / agent1.物理参数.改造模式
- agent1.改造成本倍数（来自 agent1 物理参数评估）

### 2.4 业态误判高危

**触发任一即判 red**：
- IRR < 业态门槛基准下限（商业 8% / 办公 6% / 文旅 7%）
- agent4 业态门槛对照.达标结论 = "不达标"

**字段来源**：
- agent4.IRR
- agent4.业态门槛对照.达标结论
- agent1.业态方向（用于查表）

**业态门槛基准（V1 §3 L176 / §4 L245，硬编码 lookup）**：

| 业态 | IRR 下限 | IRR 上限 |
|---|---|---|
| 商业 | 8% | 12% |
| 办公 | 6% | 9% |
| 文旅 | 7% | 10% |

### 2.5 施工引发周边协调失败高危

**同时满足以下 2 条即判 red**：
- 文保周边 / 密集区（任一为真）
- 施工扰动评估 = "高风险"

**字段来源**：
- agent1.文保周边
- agent1.密集区
- agent1.施工扰动评估

## 3. 边界区分（避免误判）

| 邻近失败模式 | 区分要点 |
|---|---|
| 招商失败 vs 业态误判 | 招商失败聚焦**物理与区位前置条件**（面积/客流）；业态误判聚焦 **IRR 测算结果**（来自 agent4） |
| 退出受阻 vs 招商失败 | 退出受阻聚焦**后端退出路径**（融资/资产属性）；招商失败聚焦**前端招商落地**（面积/客流） |
| 改造超预算 vs 施工协调 | 超预算聚焦**改造模式内部成本**（文保/结构约束）；周边协调聚焦**施工期外部环境**（密集区/扰动） |
| 业态误判 vs 招商失败 | 业态误判由 agent4 IRR 测算驱动；招商失败由物理参数驱动 |
| 施工协调 vs 改造超预算 | 周边协调聚焦**施工期外部环境**；超预算聚焦**改造模式选择** |

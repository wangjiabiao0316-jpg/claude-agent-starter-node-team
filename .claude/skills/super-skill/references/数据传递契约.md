# 数据传递契约（references/数据传递契约.md）

> super-skill 编排器把上游 agent 输出 JSON 注入下游 agent system prompt 的**格式 + 字段映射表**。
>
> 配套：架构设计 §2.2 + SKILL.md 数据传递机制章节。

---

## 1. 注入格式（system prompt 拼接）

super-skill 把上游 agent 输出 JSON 字符串拼到下游 system prompt 顶部：

```
[AGENT_CONTEXT]
{
  "agent1": {
    "agent": "agent1-固有对象",
    "灯色": "yellow",
    "产权判定": {...},
    "文保判定": {...},
    "物理参数": {...}
  },
  "agent2": {
    "agent": "agent2-政策应答",
    "试点城市合规": true,
    "适用政策Top3": [...]
  }
}
[END]

<下游 agent 自身的 system prompt 从这里开始>
```

**约束**：
- `[AGENT_CONTEXT]...[END]` 块必须在 system prompt 顶部（最先看到）
- 上游字段名保留原文（如 `灯色` / `产权判定`，不翻译）
- 跳过的 agent（H1/H2 短路）字段值为 `null`

## 2. 字段映射表

### 2.1 agent1 输出 → 下游消费

| agent1 字段 | 消费方 | 用途 |
|---|---|---|
| `灯色` | agent3 / agent5 / agent6 | agent3 H1 产权前置；agent5 案例相似度维度；agent6 设计咨询子灯 |
| `产权判定.性质`（划拨 / 出让 / 集体） | agent3 | agent3 H2 抵押物类型判定（划拨地无法抵押） |
| `文保判定.等级`（无 / 区级 / 市级 / 国家级） | agent3 / agent5 / agent6 | agent3 改造模式限制；agent5 案例相似度；agent6 设计咨询子灯 |

## 3. 跳过 / 缺失字段处置

### 3.1 H1 短路（agent1 red → agent3/4 跳过）

下游 agent6 看到的 inject_context：

```json
{
  "agent1": { ... 完整 agent1 输出，灯色="red" ... },
  "agent3": null,
  "agent4": null,
  "agent5": null
}
```

agent6 必须按 V1 §6 规则处置：设计咨询子灯 = red（agent1 red）→ 顶层灯 red（H 硬规则）。

### 3.2 H2 短路（agent3 red → agent4 跳过）

agent6 看到的 inject_context：

```json
{
  "agent1": { ... },
  "agent3": { ... 完整 agent3 输出，灯色="red" ... },
  "agent4": null,
  "agent5": { ... }
}
```

agent6 处置：投资拓展子灯 = red（agent3 red）→ 顶层灯 red（H 硬规则）。

### 3.3 子集模式（部分 agent 调用）

子集模式下，super-skill 只调用相关 agent + 强制 agent6。未调用的 agent 字段在 inject_context 中为 `null`，agent6 按 V1 §6 规则处置（缺失字段 = 子灯 yellow）。

### 3.4 追加模式（重跑部分 agent）

追加模式下，super-skill 从 `[RETRIEVED CONTEXT]` 块读已完成 agent 输出，与新跑的 agent 输出合并后注入 agent6。agent6 必须重跑（聚合依赖全部下游）。

## 4. 字段命名约定

- 中文字段名（如 `灯色` / `产权判定`）保留原文，**不**翻译成英文
- 数值字段单位在字段名后缀（如 `建筑面积_㎡` / `IRR_%`）
- 数组字段用复数（如 `适用政策Top3` / `Top3案例`）
- 内部计算字段用下划线前缀（如 `_calc.engine`）

## 5. inject_context 伪代码

```python
def inject_context_to_system_prompt(downstream_agent: str, agent_outputs: dict) -> str:
    """
    根据下游 agent 决定注入哪些上游 agent 的输出。
    返回拼接好的 [AGENT_CONTEXT]...[END] 块字符串。
    """
    INJECTION_MAP = {
        "agent3": ["agent1", "agent2"],
        "agent4": ["agent3"],
        "agent5": ["agent1", "agent3", "agent4"],
        "agent6": ["agent1", "agent3", "agent4", "agent5"],
    }
    upstream_agents = INJECTION_MAP.get(downstream_agent, [])

    context_dict = {}
    for ua in upstream_agents:
        context_dict[ua] = agent_outputs.get(ua, None)

    return f"[AGENT_CONTEXT]\n{json.dumps(context_dict, ensure_ascii=False, indent=2)}\n[END]\n\n"
```

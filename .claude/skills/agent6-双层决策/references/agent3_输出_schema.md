## 2. 字段说明

| 字段 | 类型 | agent6 引用方式 |
|---|---|---|
| `灯色` | enum: 红/黄/绿 | 投资拓展维度融资信号；`agent3.灯色=红` → 投资拓展维度 red（顶层硬规则触发） |
| `可适用融资工具清单` | object[] | `agent3.可适用融资工具清单[].期限` 用于业主平台维度（长期运营收益评估） |
| `推荐资金组合` | string | 直接 copy 到 agent6 投资拓展维度 `依据.agent3_推荐资金组合` |
| `关键审批风险点` | string[] | 直接 copy 到 agent6 投资拓展维度 `依据` 字段 |
| `依据` | string[] | 用于 agent6 输出对象 `四维子灯.投资拓展.依据.agent3_*` 字段填充 |
| `建议动作` | string | agent6 顶层 `建议动作` 的来源之一 |

## 3. agent6 投资拓展维度的协同消费（V2 新增说明）

agent6 `decision_aggregator.py` 在算投资拓展维度时，按以下优先级（高 → 低）：

1. **`agent4._calc.engine` 强制规则**（`unavailable/sandbox_error → red`，`python-bisection/timeout-at-30s → yellow`）
2. **`agent3.灯色`**：`red → red`；`yellow → yellow`；`green` 看 agent4
3. **`agent4.业态门槛对照.达标结论`**：`不达标 → red`；`达标 → yellow`；`优 → green`

> 注：agent3 + agent4 必须协同判定，agent3 灯色单维不能决定投资拓展维度（除非 agent4 engine 异常）。

## 4. H1-H4 硬约束摘要

| 编号 | 硬约束 | 触发条件（不通过 → 该工具剔除） |
|---|---|---|
| H1 | 资本金门槛 | 资本金比例 ≥ 银行贷款准入 **25-30%**；低于 → 该工具不可用 |
| H2 | 抵押物合规 | 抵押物类型在 5 类清单内（**土地 / 运营 / 收益 / 经营 / 收费权 / 组合**）且满足抵押率阈值 |
| H3 | 负面清单排除 | 项目与业主不在政策性资金负面清单库 |
| H4 | 试点资格 | 项目所在城市核对 **15 个试点城市**名单 + 城市分档 |

> 任一 H 不通过 → 该融资工具直接剔除，不进入 S 软约束评分。

## 5. S1-S4 软约束权重表【待校准】

| 编号 | 软约束 | 权重 | 评分维度 |
|---|---|---|---|
| S1 | 审批通过率 | **0.3**【待校准】 | 历史审批通过率案例库匹配 → 0-100 |
| S2 | 资金成本 | **0.3**【待校准】 | 综合利率/费率/隐性成本 → 0-100 |
| S3 | 期限匹配 | **0.2**【待校准】 | 融资期限 vs 持有年限匹配度 → 0-100 |
| S4 | 还款覆盖 | **0.2**【待校准】 | 基准租金 × 可租赁面积 还款覆盖倍数 → 0-100 |

> 4 维权重合计 1.0（0.3 + 0.3 + 0.2 + 0.2），全部【待校准】。

## 6. 可行性灯判定（结论层灯色）

- 可适用工具数 = 0 → **红**（agent6 顶层硬规则触发）
- 可适用但覆盖率 < 阈值 → **黄**
- 存在可行组合且覆盖达标 → **绿**

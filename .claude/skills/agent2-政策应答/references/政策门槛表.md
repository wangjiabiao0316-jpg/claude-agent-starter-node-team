## 一、5 维门槛查表（H1）

### 维度 1：试点城市（详见 `15-试点城市.md`）

15 试点城市：北京 / 上海 / 广州 / 深圳 / 杭州 / 成都 / 武汉 / 西安 / 重庆 / 南京 / 天津 / 长沙 / 青岛 / 郑州 / 厦门

校验要点：
- 项目所在地 ∈ 15 试点城市 → 通过
- 项目所在地 ∉ 15 试点城市 → 不符（缺口 = "项目所在地非 15 试点城市"）
- 注：仅适用于"专项债自审自发"通道；其他政策（REITs/税费减免/容积率奖励）城市覆盖更广

### 维度 2：项目类型

| 项目类型 | 适用专项债 | 适用 REITs | 适用税费减免 | 适用容积率奖励 | 适用城市专项资金 |
|---|---|---|---|---|---|
| 拆除重建 | Y | Y | 部分丧失 | Y | Y |
| 保留微更新 | Y | Y | Y（加分） | Y（加分） | Y（加分） |
| 混合（拆除 + 保留） | Y | Y | 部分 | Y | Y |
| 老旧厂房改造 | Y | Y（产业园 / 文创方向） | Y | Y | Y |
| 存量商业提质 | Y | Y（消费基础设施） | Y | Y | Y |
| 城中村改造 | Y | Y（保障房方向） | Y | Y | Y |
| 保障性租赁住房 | Y（重点支持） | Y | Y | Y | Y |
| 工业园区退出 | 部分支持 | Y（产业园区 REITs） | 部分 | 部分支持 | 部分 |

校验要点：
- 项目类型 ∈ 政策支持目录 → 通过
- 项目类型 ∉ 政策支持目录 → 不符（缺口 = "项目类型 X 不在 Y 政策支持目录"）
- 注：保留微更新通常享额外加分（历史文化保护类政策要求保留原建筑主体结构 ≥60-70%）

### 维度 3：资产规模

| 资产规模 | 适用专项债 | 适用 REITs | 适用税费减免 | 适用容积率奖励 | 适用城市专项资金 |
|---|---|---|---|---|---|
| ≥1亿（大型） | Y（重点项目） | Y（≥8亿评估值更优） | Y | Y | Y |
| 1000万-1亿（中型） | Y（普通项目） | N（评估值不达 REITs 8 亿门槛） | Y | Y | Y |
| <1000万（小型） | N（不达专项债最低规模） | N | 部分 | Y | 部分 |

校验要点：
- 资产规模 ≥ 政策最低规模门槛 → 通过
- 资产规模 < 政策最低规模门槛 → 不符（缺口 = "资产规模 X 不达 Y 政策最低门槛 Z"）
- 注：REITs 通常要求底层资产评估值 ≥8 亿；专项债通常要求项目投资 ≥1000 万

### 维度 4：业主资质

| 业主资质 | 适用专项债 | 适用 REITs | 适用税费减免 | 适用容积率奖励 | 适用城市专项资金 |
|---|---|---|---|---|---|
| 国企 / 政府平台公司 | Y（优先） | Y | Y（全面） | Y | Y（优先） |
| 民企 | 部分（需授权主体） | Y | 部分（部分政策限定国企） | Y | 部分 |
| 混合所有制 | Y（视股权结构） | Y | Y | Y | Y |
| 外资 | 部分（限制类） | 部分 | 部分 | 部分 | N |

校验要点：
- 业主资质 ∈ 政策限定范围 → 通过
- 业主资质 ∉ 政策限定范围 → 不符（缺口 = "业主资质 X 不在 Y 政策支持主体目录"）
- 注：专项债"自审自发"通常要求政府平台公司或授权主体；城市专项资金优先国企

### 维度 5：业态方向

| 业态方向 | 适用专项债 | 适用 REITs | 适用税费减免 | 适用容积率奖励 | 适用城市专项资金 |
|---|---|---|---|---|---|
| 商业（含存量商业提质） | Y | Y（消费基础设施 REITs） | Y | Y | Y |
| 办公 | Y | 部分 | Y | Y | Y |
| 文旅 | Y | 部分 | Y | 部分 | Y |
| 工业仓储（含产业园） | Y | Y（产业园区 / 仓储物流 REITs） | 部分 | 部分 | Y |
| 居住（含保障房） | Y（重点支持保障房） | Y（保障房 REITs） | Y | Y | Y |
| 公共服务（含教育/医疗/养老） | Y | Y（部分） | Y | 部分 | Y |
| 数据中心 | N（不在专项债支持目录） | 部分 | 部分 | N | N |
| 元宇宙主题公园 | N | N | N | N | N |
| 高耗能 / 高污染 | N | N | N | N | N |

校验要点：
- 业态方向 ∈ 政策支持目录 → 通过
- 业态方向 ∉ 政策支持目录 → 不符（缺口 = "业态方向 X 不在 Y 政策支持目录"）
- 注：数据中心、元宇宙、高耗能通常不在专项债支持目录；保障性租赁住房、城市更新、产业园区为重点支持方向

## 二、S1 适用强度评分参考（权重 0.5【待校准】）

### S1 评分区间

| 区间 | 描述 | 典型场景 |
|---|---|---|
| 90-100 | 高额度 + 长期限 + 高减免比例 | 专项债额度 > 项目投资 30% + 期限 ≥ 20 年；REITs 估值溢价 15-25% + 税收递延 |
| 70-89 | 中等支持 | 税费减免 30-50% + 期限 5-10 年；容积率奖励 10-20% |
| 50-69 | 一般支持 | 容积率奖励 ≤ 10%；象征性资金补贴 |
| 0-49 | 象征性支持或条款模糊 | 条款表述模糊、实操落地不明 |
| 0 | 不适用 | H1 门槛不符（不应进入 S1 评分） |

### S1 评分细分（按政策类型）

#### 专项债
- 高额度（≥ 项目投资 30%）+ 长期限（≥ 20 年）→ 90-100
- 中额度（10-30%）+ 中期限（10-20 年）→ 70-89
- 低额度（< 10%）+ 短期限（< 10 年）→ 50-69

#### REITs
- 估值溢价 ≥ 20% + 分派率 ≥ 4% + 完整税收递延 → 90-100
- 估值溢价 10-20% + 分派率 4-5% + 部分税收递延 → 70-89
- 估值溢价 ≤ 10% + 分派率 4% → 50-69

#### 税费减免
- 减免比例 ≥ 50% + 期限 ≥ 5 年 + 多税种叠加 → 90-100
- 减免比例 30-50% + 期限 5-10 年 → 70-89
- 减免比例 ≤ 30% + 期限 ≤ 5 年 → 50-69

#### 容积率奖励
- 奖励幅度 ≥ 20% + 不限业态 → 90-100
- 奖励幅度 10-20% + 业态限定 → 70-89
- 奖励幅度 ≤ 10% → 50-69

#### 城市专项资金
- 单项目最高额度 ≥ 5000 万 → 90-100
- 单项目最高额度 1000-5000 万 → 70-89
- 单项目最高额度 ≤ 1000 万 → 50-69

## 三、S2 申请路径可行性评分参考（权重 0.5【待校准】）

### S2 评分区间

| 区间 | 描述 | 典型场景 |
|---|---|---|
| 90-100 | 申报通道明确 + 同城有公开成功案例 + 审批周期 ≤ 6 个月 | 北京/上海/广州/深圳同类项目历史案例丰富 |
| 70-89 | 通道明确 + 异地有参考案例 + 审批周期 6-12 个月 | 强二线城市（杭州/成都/武汉等）参考先例 |
| 50-69 | 通道部分明确 + 案例稀缺 + 审批周期 12-18 个月 | 弱二线 / 三线城市，需部门联审 |
| 0-49 | 通道不明 + 无公开案例 + 审批周期 > 18 个月或不可预计 | 政策刚出台、试点阶段、无落地案例 |

### S2 评分细分（按政策类型）

#### 专项债（自审自发）
- 试点城市（北京/上海等 15 城）+ 同类案例 ≥3 起 + 审批 ≤6 个月 → 90-100
- 试点城市 + 同类案例 1-2 起 + 审批 6-12 个月 → 70-89
- 试点城市 + 同类案例稀缺 + 审批 12-18 个月 → 50-69

#### REITs
- 发改委项目库 + 证监会注册双轨 + 同类资产上市 ≥5 起（如产业园区 / 仓储物流）→ 90-100
- 双轨通道 + 同类资产上市 1-4 起 → 70-89
- 双轨通道 + 同类资产上市为 0 → 50-69

#### 税费减免
- 市级税务部门联审 + 同城同类案例 ≥3 起 + 审批 3-6 个月 → 90-100
- 市级税务部门 + 异地参考案例 + 审批 6-12 个月 → 70-89
- 跨部门联审 + 案例稀缺 + 审批 12-18 个月 → 50-69

#### 容积率奖励
- 自然资源部门单审 + 同城同类案例丰富 + 审批 ≤3 个月 → 90-100
- 自然资源部门 + 部分案例参考 + 审批 3-6 个月 → 70-89
- 多部门联审 + 案例稀缺 + 审批 ≥6 个月 → 50-69

#### 城市专项资金
- 住建 / 财政跨部门 + 同城同类案例丰富 + 审批 6 个月 → 90-100
- 跨部门 + 部分案例参考 + 审批 6-12 个月 → 70-89
- 跨部门 + 案例稀缺 + 审批 ≥12 个月 → 50-69

## 四、综合分参考区间（S1 × 0.5 + S2 × 0.5）

| 综合分区间 | 推荐等级 | 说明 |
|---|---|---|
| 85-100 | 强烈推荐（Top1 候选） | 政策支持力度大 + 申报路径明确，应优先推进 |
| 70-84 | 推荐（Top2-Top3 候选） | 政策支持力度中等 + 路径较明确，可并行推进 |
| 55-69 | 谨慎推荐（备选） | 政策支持力度一般或路径不明确，需细化评估 |
| 0-54 | 不推荐 | 通常因 H1 门槛不符已剔除；如出现在可适用清单 → 重新评估 |

### 综合分计算范例

```
S1 = 85（专项债高额度 + 长期限）
S2 = 80（同城 3 例 + 审批 6 个月）
综合分 = 85 × 0.5 + 80 × 0.5 = 42.5 + 40.0 = 82.5

S1 = 78（城市专项资金中等额度）
S2 = 70（异地参考 + 审批 6-12 个月）
综合分 = 78 × 0.5 + 70 × 0.5 = 39.0 + 35.0 = 74.0

S1 = 88（REITs 估值溢价 + 税收递延）
S2 = 72（双轨通道 + 1-4 起参考案例）
综合分 = 88 × 0.5 + 72 × 0.5 = 44.0 + 36.0 = 80.0
```

## 五、5 维门槛 + S1/S2 评分的查表流程

1. **提取用户问题的 5 维信息**：
   - 项目所在地（→ 城市）
   - 项目类型（→ 拆除重建 / 保留微更新 / 混合 / 老旧厂房改造 / 存量商业提质 / 城中村改造 / 保障房 / 工业园区退出）
   - 资产规模（→ ≥1亿 / 1000万-1亿 / <1000万）
   - 业主资质（→ 国企 / 民企 / 混合所有制 / 外资）
   - 业态方向（→ 商业 / 办公 / 文旅 / 工业仓储 / 居住 / 公共服务 / 数据中心 / 元宇宙 / 高耗能）

2. **逐条候选条款查表**：
   - 维度 1：城市 ∈ 15 试点？
   - 维度 2：项目类型 ∈ 政策支持目录？
   - 维度 3：资产规模 ≥ 政策门槛？
   - 维度 4：业主资质 ∈ 政策限定范围？
   - 维度 5：业态方向 ∈ 政策支持目录？
   - 任一不符 → 门槛不符，列入"未适用政策及原因"，附具体缺口
   - 全部通过 → 进入 S1/S2 评分

3. **S1/S2 评分**（参考本表"二"和"三"章节）
4. **综合分计算**：`S1 × 0.5 + S2 × 0.5`（保留 1 位小数）
5. **降序排序，取 Top1-Top3**

## 六、常见组合的查表参考

### 组合 A：北京 + 老旧厂房改造 + ≥1亿 + 国企 + 文创
- H1：北京 ∈ 15 城 ✓ / 老旧厂房改造 ∈ 专项债支持 ✓ / ≥1亿 ✓ / 国企 ✓ / 文创 ∈ 支持 ✓
- S1：90+（专项债 + 城市专项资金叠加 + 历史文化保护加分）
- S2：90+（北京同城案例丰富）
- 综合分：90+

### 组合 B：上海 + 存量商业提质 + ≥1亿 + 民企 + 商业
- H1：上海 ∈ 15 城 ✓ / 存量商业提质 ✓ / ≥1亿 ✓ / 民企部分政策受限 / 商业 ✓
- S1：85（专项债 + 商业 REITs）
- S2：85（上海同城案例丰富）
- 综合分：85

### 组合 C：河南 + 老旧厂房改造 + ≥1亿 + 国企 + 商业
- H1：河南 ∉ 15 城 ✗ → 专项债自审自发门槛不符
- 缺口："项目所在地河南非 15 试点城市"
- 但其他政策（一般专项债 / 税费减免 / 容积率奖励）可继续匹配
- 一般专项债综合分：65-70（非自审自发，普通通道）

### 组合 D：北京 + 数据中心 + ≥1亿 + 国企 + 数据中心
- H1：北京 ∈ 15 城 ✓ / 数据中心 ∉ 专项债支持目录 ✗ → 专项债门槛不符
- 缺口："业态方向数据中心不在专项债支持目录"
- 但其他政策（税费减免 / 容积率奖励）部分可适用
- 综合分：通常 50-60（数据中心限制类）

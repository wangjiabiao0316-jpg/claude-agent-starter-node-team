## 场景一：专项债资格（含 15 城门槛边界）

### 场景描述
城市更新 / 存量改造项目业主询问能否申请地方政府专项债"自审自发"通道（覆盖 15 试点城市资格判定 + 项目类型匹配 + 申报路径可行性）。

### 典型问句
- "我们这个项目能拿专项债吗？"
- "上海某存量商业提质改造，专项债资格 + 申报路径？"
- "[XX 城市某业态]可以申请专项债自审自发吗？"
- "北京某老旧厂房改造能不能走专项债通道？"
- "杭州某数字产业园 5 亿投资能申请专项债吗？"

### F1 检索关键词（fallback 匹配用）
- 强关键词：专项债 / 自审自发 / 地方政府债券 / 15 试点城市
- 弱关键词：城市更新资金 / 省级财政厅 / 项目资本金 / 专项债项目库

### H1 门槛要点
1. **试点城市资格**：项目所在地 ∈ 15 城（北京/上海/广州/深圳/杭州/成都/武汉/西安/重庆/南京/天津/长沙/青岛/郑州/厦门）
2. **项目类型**：城市更新 / 基础设施 / 公共服务 / 存量资产盘活 / 老旧厂房改造 / 存量商业提质 / 城中村改造 / 保障性租赁住房
3. **资产规模**：≥ 1000 万（小型项目门槛）；重点项目 ≥ 1 亿
4. **业主资质**：政府平台公司或授权主体（民企需特许经营授权）
5. **业态方向**：商业 / 办公 / 文旅 / 工业仓储 / 居住 / 公共服务（数据中心 / 元宇宙 / 高耗能通常不在支持目录）

### S1 适用强度（权重 0.5）
- 资金额度：专项债额度可达项目投资 30%（一线）/ 10-20%（强二线）
- 期限长度：10-15 年（普通）/ 20 年（重点）
- 利率优惠：较 LPR 下浮 100-150bp

### S2 申请路径可行性（权重 0.5）
- 申报通道：省级财政厅 → 财政部专员办（自审自发试点省级权限直接审）
- 历史案例：试点城市同城同类案例（北京/上海 ≥10 起 / 强二线 3-8 起）
- 审批周期：3-6 个月（自审自发试点）/ 6-12 个月（一般专项债）

### 示例可适用政策片段

```json
{
  "政策名称": "专项债自审自发（试点城市，北京 + 老旧厂房改造）",
  "支持力度": "S1=90/100，资金额度可达项目投资 30%，期限 20 年，利率较 LPR 下浮 100-150bp",
  "申请路径": "S2=85/100，北京市财政局自审自发通道，审批周期 3-6 个月，近 12 月同类案例 12 起",
  "限制条件": "仅限 15 试点城市/省内项目；项目类型须在城市更新支持目录；业主须为政府平台公司或授权主体",
  "依据条款": "国发〔2024〕XX 号 / 财预〔2024〕XX 号 / 京财税〔2024〕XX 号",
  "综合分": "87.5"
}
```

> 综合分公式：`综合分 = S1 × 0.5 + S2 × 0.5 = 90 × 0.5 + 85 × 0.5 = 87.5`

### 门槛不符示例（15 城边界）

**Q**：河南某老旧厂房改造能否申请专项债自审自发？
**A**：
- H1 维度 1：河南 ∉ 15 试点城市 → 门槛不符
- 缺口："项目所在地河南非 15 个专项债自审自发试点城市"
- 建议：改走一般专项债渠道（非自审自发），由河南省财政厅转报财政部
- 综合分：65（一般专项债 S1=70 + 河南异地 S2=60）

## 场景二：政策奖励（城市专项资金 + 税费减免 + 容积率奖励）

### 场景描述
业主流转 / 改造项目询问是否符合城市专项资金 / 税费减免 / 容积率奖励等政策奖励条款（业态方向 / 改造模式 / 投资规模多维度匹配）。

### 典型问句
- "我们项目有哪些政策奖励可以申请？"
- "[XX 城市某老旧厂房改造]能拿专项资金补贴吗？"
- "容积率奖励怎么申请？"
- "文创园区改造有没有节能补贴 + 历史文化保护双重奖励？"
- "上海旧改 35 条能不能同时享受？"

### F1 检索关键词（fallback 匹配用）
- 强关键词：城市专项资金 / 税费减免 / 容积率奖励 / 历史文化保护奖励
- 弱关键词：节能改造补贴 / 文创科创扶持 / 老旧小区改造专项资金 / 城市更新条例

### H1 门槛要点
1. **城市**：政策覆盖通常 ≥15 城（部分政策全国适用）
2. **项目类型**：保留微更新加分（历史文化保护类要求保留原建筑主体结构 ≥60-70%）
3. **资产规模**：部分专项资金设最低投资门槛（≥1 亿）
4. **业主资质**：国企 / 政府平台公司优先；民企需授权主体
5. **业态方向**：文创 / 科创 / 养老 / 文旅 / 历史保护（重点支持）；数据中心 / 高耗能（不支持）

### S1 适用强度
- 奖励额度：城市专项资金最高 1000-5000 万 / 税费减免 30-50% / 容积率奖励 10-20%
- 期限：一次性（专项资金）/ 5-10 年（税费减免）/ 永久（容积率奖励）
- 多条款叠加可行性：专项资金 + 税费 + 容积率（部分政策可叠加）

### S2 申请路径可行性
- 申报通道：住建 / 文旅 / 发改 / 财政跨部门联审
- 历史案例：同城市同业态先例
- 审批复杂度：单部门（容积率 1-3 个月）/ 多部门联审（4-12 个月）

### 示例可适用政策片段

```json
{
  "政策名称": "城市更新历史文化保护专项资金（北京）+ 历史建筑改造税费减免（房产税 + 土地使用税）",
  "支持力度": "S1=85/100，专项资金最高 5000 万元 + 房产税免征 5 年 + 土地使用税减半 + 容积率奖励上浮 10%",
  "申请路径": "S2=80/100，北京市住建委 + 文旅局 + 税务局联审通道，审批周期 4-6 个月，近 12 月同类案例 6 起",
  "限制条件": "业态须为历史文化保护类；改造模式须保留原建筑主体结构 ≥70%；投资规模 ≥1 亿元；业主须为国企或政府平台公司",
  "依据条款": "《北京城市更新条例》§XX / 《北京市历史文化保护专项资金管理办法》/ 财税〔2023〕XX 号",
  "综合分": "82.5"
}
```

> 综合分公式：`综合分 = S1 × 0.5 + S2 × 0.5 = 85 × 0.5 + 80 × 0.5 = 82.5`

## 场景三：REITs 退出（基础设施 / 商业 / 消费）

### 场景描述
存量资产运营方询问项目退出能否走基础设施 REITs 通道（资产类型 / 规模 / 运营年限 / 现金流稳定性多重门槛校验）。

### 典型问句
- "我们产业园区退出能走 REITs 吗？"
- "商业 REITs 申报需要什么条件？"
- "REITs 估值怎么算？"
- "广东某仓储物流资产 8 亿估值能不能做 REITs？"
- "深圳某消费基础设施 REITs 怎么申报？"

### F1 检索关键词（fallback 匹配用）
- 强关键词：基础设施 REITs / 商业 REITs / 消费基础设施 REITs / 资产证券化
- 弱关键词：退出通道 / 产业园 REITs / 保障房 REITs / 仓储物流 REITs / 发改委 + 证监会双审

### H1 门槛要点
1. **城市**：REITs 试点覆盖 ≥15 城（产业园区 / 仓储物流 / 保障房 / 消费基础设施等）
2. **资产类型**：产业园 / 仓储物流 / 保障房 / 消费基础设施 / 清洁能源 / 高速公路等
3. **资产规模**：评估值 ≥ 8 亿元（重点支持 ≥10 亿）
4. **运营年限**：≥ 3 年（部分品类可放宽至 1.5 年）
5. **现金流**：分派率 ≥ 4% / 租金可预测性强 / 现金流稳定
6. **业主**：无重大违约 / 法律纠纷 / 信用记录良好

### S1 适用强度
- 估值溢价：较散售 / 整售溢价 15-25%
- 退出期限：封闭期 20-30 年（续期机制）
- 税收优惠：企业所得税 + 增值税 + 土地增值税递延

### S2 申请路径可行性
- 申报通道：发改委项目库 + 证监会注册双轨
- 历史案例：同类资产上市先例（产业园区 / 仓储物流 ≥10 起 / 消费基础设施 1-4 起）
- 审批周期：12-18 个月（普通）/ 18-24 个月（创新品类）

### 示例可适用政策片段

```json
{
  "政策名称": "基础设施 REITs（产业园区类，广东）",
  "支持力度": "S1=88/100，估值溢价约 15-25%，分派率 4-5%，税收递延覆盖所得税/增值税/土增税",
  "申请路径": "S2=82/100，发改委项目库申报 + 证监会注册双轨，审批周期 12-18 个月，广东同类案例 6 起",
  "限制条件": "资产评估值 ≥8 亿；运营 ≥3 年；近 3 年现金流稳定且分派率 ≥4%；业态须为产业园/仓储物流/保障房/消费基础设施等 REITs 支持目录",
  "依据条款": "证监会公告〔2020〕XX 号 / 发改办投资〔2023〕XX 号",
  "综合分": "85.0"
}
```

> 综合分公式：`综合分 = S1 × 0.5 + S2 × 0.5 = 88 × 0.5 + 82 × 0.5 = 85.0`

### 门槛不符示例（资产类型不匹配）

**Q**：北京某仓储用地改数据中心，能否拿 REITs？
**A**：
- H1 维度 5：数据中心 ∉ REITs 支持目录（仅产业园 / 仓储物流 / 保障房 / 消费基础设施 / 清洁能源 / 高速公路）→ 门槛不符
- 缺口："业态方向数据中心不在 REITs 支持目录"
- 建议：可改租用给云服务商（租金模式），不直接走 REITs；或转型为"产业园区 + 数据服务"混合业态

## 场景四：税费减免（房产税 / 土地使用税 / 增值税即征即退 / 契税减免）

### 场景描述
项目业主询问能否享受城市更新税费减免（房产税 / 土地使用税 / 增值税即征即退 / 契税减免等多税种组合判定）。

### 典型问句
- "老旧厂房改造能免房产税吗？"
- "城市更新项目有哪些税费减免？"
- "改造后土地使用税怎么算？"
- "历史建筑改造增值税能即征即退吗？"
- "城中村改造契税能免吗？"

### F1 检索关键词（fallback 匹配用）
- 强关键词：房产税减免 / 土地使用税减免 / 增值税即征即退 / 契税减免 / 城市更新税收优惠
- 弱关键词：历史建筑减免 / 企业所得税加计扣除 / 保障房税收优惠

### H1 门槛要点
1. **城市**：政策覆盖全国（部分城市有地方性补充）
2. **项目类型**：历史建筑 / 老旧小区 / 危房 / 棚改 / 保障房（重点支持）
3. **资产规模**：通常无明确门槛（部分地方政策设 ≥1000 万门槛）
4. **业主资质**：国企 / 政府平台公司（部分政策限定）/ 民企（部分政策适用）
5. **业态用途**：公益用途（享全额减免）/ 经营性用途（部分减免）

### S1 适用强度
- 减免比例：免征（100%）/ 减半（50%）/ 比例减免（30-50%）
- 期限：项目期 / 运营期 5 年 / 长期
- 税种覆盖：单税种（房产税）vs 多税种叠加（房产税 + 土地使用税 + 增值税 + 契税）

### S2 申请路径可行性
- 申报通道：市级税务部门 + 财政部门联审
- 历史案例：同城市同业态先例
- 审批周期：3-6 个月（部分高复杂度 6-12 个月）

### 示例可适用政策片段

```json
{
  "政策名称": "城市更新历史建筑改造税费减免（房产税 + 土地使用税 + 增值税即征即退）",
  "支持力度": "S1=82/100，房产税免征 5 年 / 土地使用税减半 / 增值税即征即退 50%（多税种叠加覆盖）",
  "申请路径": "S2=76/100，市级税务部门联审，审批周期 3-6 个月，近 12 月同类案例 5 起",
  "限制条件": "项目类型须为历史建筑 / 老旧小区 / 危房；改造模式须保留原建筑主体结构 ≥60%；仅限政府平台公司或授权实施主体",
  "依据条款": "财税〔2023〕XX 号 / XX 市城市更新税费减免实施细则",
  "综合分": "79.0"
}
```

> 综合分公式：`综合分 = S1 × 0.5 + S2 × 0.5 = 82 × 0.5 + 76 × 0.5 = 79.0`

## 场景五：单一维度查询（专项债资格边界）

### 场景描述
用户仅问单一政策维度（如专项债）的资格判定，agent2 仅激活与该维度相关的政策候选，不输出无关政策。

### 典型问句
- "我们项目能拿专项债吗？"（不问其他政策）
- "我们项目能走 REITs 吗？"（仅 REITs）
- "我们项目房产税能免吗？"（仅房产税）

### 处理逻辑
- 仅匹配与所问政策类型相关的候选条款（如"专项债"→ 仅匹配专项债条款，不输出 REITs / 税费减免）
- 综合分排序仅在该维度内进行
- H1 5 维门槛仍逐条校验

### 示例输出（仅问专项债）

```json
{
  "业务问题": "上海某存量商业提质改造（5 亿），仅问专项债资格",
  "可适用政策清单": [
    {
      "政策名称": "上海市专项债自审自发存量资产盘活支持条款",
      "支持力度": "S1=85，专项债额度可达项目投资的 30%，期限 20 年",
      "申请路径": "S2=82，上海已公开 3 例存量商业提质成功案例，审批周期约 6 个月",
      "限制条件": "项目类型为存量资产盘活（含商业提质）；业主需具备房地产开发一级资质；项目估值 ≥5 亿元",
      "依据条款": "《上海市专项债券项目库管理办法》第 14 条",
      "综合分": "83.5"
    }
  ],
  "未适用政策及原因": [],
  "建议动作": "建议优先对接上海市发改委专项债项目库，同步准备房地产开发一级资质证明与项目估值报告"
}
```

## 场景六：多维组合查询（专项资金 + 税费减免 + 容积率奖励）

### 场景描述
用户询问多项政策能否同时享受（如"专项资金 + 税费减免 + 容积率奖励"），agent2 需逐条匹配每项政策并标注叠加可行性。

### 典型问句
- "重庆某文旅项目：专项资金 + 税费减免 + 容积率奖励三项能否同时享受？"
- "上海旧改项目：专项债 + 城市专项资金 + 房产税减免能叠加吗？"
- "杭州未来社区：专项资金 + 容积率奖励 + 城市更新基金能叠加吗？"

### 处理逻辑
- 逐条匹配每项政策（专项债 / 城市专项资金 / 税费减免 / 容积率奖励）
- 每条独立计算综合分
- 在"建议动作"中明确说明叠加可行性（部分政策可叠加 / 部分互斥）

### 示例输出（重庆文旅 + 三政策叠加）

```json
{
  "业务问题": "重庆某文旅项目：专项资金 + 税费减免 + 容积率奖励三项能否同时享受？",
  "可适用政策清单": [
    {
      "政策名称": "重庆市文旅消费 REITs + 城市更新专项资金（文旅方向）",
      "支持力度": "S1=80，专项资金最高 3000 万 + 容积率奖励上浮 10%",
      "申请路径": "S2=75，重庆市住建委 + 文旅委联审通道，审批周期 6-9 个月",
      "限制条件": "业态须为文旅；改造模式须保留原建筑主体结构 ≥60%；投资规模 ≥5000 万元",
      "依据条款": "《重庆市城市更新条例》§XX + 渝文旅〔2024〕XX 号",
      "综合分": "77.5"
    }
  ],
  "未适用政策及原因": [
    {
      "政策名称": "重庆市房产税免征 5 年",
      "不适用原因": "门槛不符 - 业态方向文旅非保障房 / 历史建筑，不在房产税免征目录"
```
